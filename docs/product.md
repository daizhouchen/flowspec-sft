# 产品说明

FlowSpec 将中文业务任务编译成可检查、可修改、可模拟的结构化工作流。它服务于需要低风险搭建 Agent 流程的产品和运营团队。

系统坚持“先校验，再执行”：模型输出必须经过 JSON Schema、工具参数、DAG、条件和权限检查。公开 Demo 只运行沙箱，不连接真实邮箱、数据库或企业消息系统。

## MVP

- WorkflowSpec v1
- 18 个虚拟工具与六类控制结构
- 2,200 条合成样本和无模板泄漏的固定切分
- Qwen3 0.6B / 1.7B QLoRA 配置
- 编译、校验、单次修复、沙箱模拟
- FastAPI、React/Vite、Docker
